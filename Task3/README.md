Project Title

Online Examination System using Java Swing (GUI)

Description

This project is an Online Examination System developed using Java Swing.  
It provides a simple interface for students to login, attend exams, and view results with a timed quiz system.
  User Login (Username & Password)
  Attend Online Exam (MCQ Questions)
  Timer for Exam
  Auto Submit when time is over
  Profile Update (User details modification)
  Result Calculation & Display

The system begins with a login page where users must enter the correct username and password to access the examination portal. After successful login, the exam page is displayed with multiple-choice questions and a countdown timer. Users can select answers and submit the exam before the timer ends.

The application automatically checks the selected answers and displays the final score along with correct and wrong answers. If the timer reaches zero, the exam gets auto-submitted automatically.

Features

User Login Authentication,

Multiple Choice Questions,

Timer-Based Examination,

Automatic Exam Submission,

Score Calculation System,

Answer Evaluation,

Reset Answers Option,

Update Profile Feature,

Logout Functionality,

User-Friendly Java Swing GUI.

Technologies Used

Java,

Swing,

AWT.
