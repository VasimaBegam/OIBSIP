Project Title

Online Reservation System using Java GUI

Description

The Online Reservation System is a Java GUI-based application developed to manage online reservations efficiently. This project allows users to book, view, and cancel reservations through an interactive graphical user interface.
The Online Reservation System is a simple Java Swing based application developed for train ticket reservation. This project provides a graphical user interface where users can log in, book train tickets, generate a PNR number, and cancel reservations easily.
Users can enter passenger details like name, train number, train name, source station, destination station, and journey date while booking tickets. After successful booking, the system automatically generates a random PNR number and displays the booking confirmation details.

The cancellation module allows users to cancel tickets by entering the generated PNR number. If the entered PNR matches the booked ticket, the reservation gets cancelled successfully.

Technologies Used

Java,

Swing,

AWT

Features

User Login Authentication,

Train Ticket Booking,

Automatic PNR Generation,

Booking Confirmation Display,

Ticket Cancellation Using PNR,
